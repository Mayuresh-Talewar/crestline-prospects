## 1. Build method
- Files, all in `docs/brochure-capacite/build/`: `keystone.html` (all 16 pages, in reader order), `keystone.css`, `export.mjs`, output in `build/out/`. One HTML file, no framework, no chart library, no JS in the page except the QR.
- Fonts: one `<link>` to Google Fonts: IBM Plex Serif 400,500; Plex Sans 400,500,600; Plex Mono 400,500; `display=block`. Nothing else may render text.
- Page box: `@page { size: 216mm 303mm; margin: 0 }`. Each page is `<section class="page recto|verso" data-n="1..16">`, 216 x 303 mm, `position:relative; overflow:hidden; break-after:page`. All coordinates in this brief are **mm from the trim's top-left**; CSS adds the 3 mm bleed offset (`--b:3mm`). Navy fields, cover curves and the p16 band run to the page edge (bleed); nothing else does.
- Charts: inline SVG with `viewBox` in mm and `width/height` in mm, so geometry is exact. One hidden `<svg>` at the top holds the six jelly `linearGradient`s, ids `j-blue j-green j-amber j-red j-purple j-slate`, `x1=0 y1=.41 x2=1 y2=.59` (= CSS 100deg), stops exactly as v2 §4. Every data mark carries `data-v="<the printed number>"`; every chart root carries `data-scale` (mm per unit) and `data-axis="x|y"`. I check length = v x scale ±0.1 mm.
- Units: 1 pt = 0.3528 mm. Strokes 0.4 / 0.5 / 0.75 / 2 / 2.5 pt = 0.141 / 0.176 / 0.265 / 0.706 / 0.882 mm. SVG text 9 / 10.5 / 14 pt = 3.175 / 3.704 / 4.939 mm. Bar with rounded data end (r = 1.5): `M x,yb V yt+r A r r 0 0 1 x+r,yt H x+w-r A r r 0 0 1 x+w,yt+r V yb Z` (mirror for horizontal bars).
- QR (p15): generate with the installed `qrcode-generator` (error level M), inlined as SVG, 22 x 22 mm, encoding exactly `https://www.crestlineintelligence.com/book-a-demo`.
- Export: `npm i --no-save playwright-core` (no browser download, package.json untouched), then `export.mjs` launches `chromium.launch({channel:"msedge"})` (Edge is the installed browser), `goto` the file URL, awaits `document.fonts.ready` AND an explicit `document.fonts.load()` for every face/weight used (a first probe embedded only 2 of 3 families when it did not wait), then `page.pdf({path:"out/keystone-print.pdf", preferCSSPageSize:true, printBackground:true})`. PNGs: viewport 817 x 1146, `deviceScaleFactor:2`, `locator(".page").nth(i).screenshot()` to `out/p01.png`..`p16.png`; then reader-order proofs trimmed of bleed: `out/spread-1.png` (p1 alone), `spread-2-3.png` ... `spread-14-15.png`, `spread-16.png`, on a #E6E8EC ground with 0 mm between facing pages.
- Logo: the vector path from `public/crestline-mark.svg` (never the 48 px PNG), `fill: currentColor`, 8 mm tall, with "Crestline Intelligence" in Plex Sans SemiBold beside it. White on navy, navy #22396F on white, as the product itself renders it (`components/shell/logo.tsx`). OVERRULE-pending: the source file is orange #C2410C; if the client wants orange on white pages, it is a one-line change. Ask, do not guess.
## 2. Grid, margins, running elements
- Trim A4 210 x 297. Saddle-stitch: odd pages are rectos (spine on the LEFT), even pages versos (spine on the RIGHT). **Recto:** text area x 22 to 194. **Verso:** x 16 to 188. Both: y 18 to 277. Text width 172 mm, 12 columns of 10.667 mm, 4 mm gutters; column n starts at left + (n-1) x 14.667. Baseline 14 pt (4.94 mm). Nothing enters the inner 22 mm except bleed fields; no element crosses the gutter; each page stands alone.
- Running header (p2-16): baseline y 13, Plex Mono 9 pt uppercase, tracking 8%, section left, "Project Keystone" right; 0.5 pt hairline at y 15 across the text width. Navy pages: #C3CBDD text, #597BCC rule.
- Running footer (p2-16): baseline y 287, Plex Sans 9 pt #5F6670 (#C3CBDD on navy), text exactly as v2, aligned to the OUTER edge: right on rectos, left on versos. The printer imposes; we deliver single pages in reader order.

## 3. Cover (page 1): "the tide line"
Concept: a quiet, numbered confidential file whose lower third is a navy tide with one long, perfectly smooth edge and five fine contour lines above it, like water marks rising on a page. It is kept because it is almost empty, exact and personal: Copy 1 of 1, issued to him by name, nothing to read except the title, on heavy uncoated white board that feels like an object, not a mailer.
- SVG over the whole page, `viewBox="-3 -3 216 303"`. Navy field `#22396F`: `M -3,205 C 55,250 125,232 213,188 L 213,300 L -3,300 Z` (computed: 207.3 at x 0, lowest 231.1 at x 74, 189.5 at x 210, max slope 0.73: smooth, no corners).
- Contours = the open edge `M -3,205 C 55,250 125,232 213,188` repeated with `transform="translate(0,-7|-14|-21|-28|-35)"`, `fill:none`, strokes as v2 (0.9 pt #597BCC ... 0.4 pt #C3CBDD). A vertical translation, not a true offset: spacing narrows to 81% on the steepest stretch, which is how contour lines read. **OVERRULE: no contour lines inside the navy.** v2's own lines at +9/+18 mm reach y 240/249 above the confidentiality block, which must start near y 252: that breaks v2's own 15 mm clearance. The navy stays flat and silent.
- Text on the curve: a copy of the edge translated -37 (2 mm above the top contour, so glyphs never touch the stroke), `<textPath>` "From work done to cash in the bank", Plex Mono 9 pt (3.175), uppercase, `letter-spacing:.381` (12%), navy; `startOffset` tuned so the first glyph starts at x 29-31. It runs about 78 mm, y 189 to 196. The only curved text in the book.
- Straight text, recto margins: top right, right-aligned to x 194, first baseline y 22, Plex Serif 10/14 pt ink: "Copy No. 1 of 1" / "Issued to: Mr. Rohit Katyal, Executive Chairman," / "Capacite Infraprojects Limited". Title block from x 22: 0.5 pt navy hairline at y 62, **OVERRULE length 142.7 mm (10 columns), not 110: the 46 pt title is 130.7 mm wide**; "Project Keystone" Plex Serif Medium 46 pt, baseline y 80; "Working-capital review of Capacite Infraprojects Limited" Plex Sans 14 pt #5F6670 baseline y 89; "October 2026" Plex Mono 10 pt baseline y 96; second hairline y 101. In the navy, from x 22: "Strictly Private & Confidential" Plex Sans SemiBold 11 pt white, baseline y 256; "Prepared for the addressee only. Please do not forward or copy." 9 pt #C3CBDD (6.86:1) baseline y 261.5; white logo row, bottom at y 277. Clearances: title to text-path 88 mm; navy edge to first navy line 21 mm.
- Production (cover sheet = pages 1, 2, 15, 16): 300 gsm uncoated bright white; navy printed solid, TAC under 300%. Optional, printer-dependent: soft-touch matt laminate on the OUTSIDE only (p1, p16); never on p2 or p15, which take wet ink (the signature, tick boxes, the P.S.).

## 6. Acceptance tests I will run (Mode 2)
1. Numbers: extract text per page from the PDF; every ₹, days, %, x and index token must appear in v2 for that page (or in §5 above). One extra or changed figure = blocker. Spot-check sums: 1,313.5 + 1,176.8 = 2,490; 182.8 + 163.8 = 346.6; band totals 90.4 and 128.2; 1,839 - 1,376 - 136 = 327 vs 324 noted.
2. Geometry: every `data-v` x `data-scale` within ±0.1 mm of the drawn length; cover edge sampled at x 0/74/210 = 207.3/231.1/189.5 ±0.5; every cover text ≥ 15 mm from every contour.
3. Dates: every page 2-16 has a note containing a document name and a date matching `(\d{1,2} )?(May|July) 2026`; AR always "July 2026" with no day; IP always month only.
4. AI tells: grep finds 0 em/en dashes, 0 v2 buzzwords, 0 `box-shadow|filter|backdrop|blur`, 0 gradients outside the six jelly defs, 0 eyebrows above headlines, 0 icons, 0 exclamation marks.
5. Size: computed font-size ≥ 12 px (9 pt) for every HTML text node, ≥ 3.175 for every SVG text; hairlines ≥ 0.176 mm except the one 0.141 contour.
6. Contrast: every text/background pair ≥ 4.5:1 measured (tick #6F7783 4.52; muted #5F6670 5.80; #C3CBDD on navy 6.86).
7. Gutter and margins: no text or mark inside the inner 22 mm or outside the text area (bleed fields excepted); footer folio outer-aligned and reading n / 16 on pages 2-16.
8. PDF: 16 pages, MediaBox 612 x 858.96 pt, embedded fonts IBMPlexSerif/Sans/Mono only (no fallback face).
9. QR decodes to the exact URL (phone camera + a decoder). Day names: Wed 21 and Fri 23 October 2026 (checked).
10. Visual: reader-order spreads side by side against v2 and the refs: one focal point per page, headline ≤ 2 lines with no orphan word, nothing reads across the gutter, the cover holds at arm's length (thumbnail 25%) and at 100%.
Not testable by me: CMYK conversion and stock behaviour (printer's hard proof), wet-ink signature.

# Niraj Cement Structurals: how Crestline fits (NC-S23, 2026-10-09)

Business: civil EPC contractor, standalone FY26 revenue from operations Rs 540.44 Cr, 71% of it through 13 joint ventures (Annual Report FY26). Crestline is project-centric, so the unit it reads is a project, which here is mostly a joint venture.

| Question at Niraj | Crestline screen | True today |
|---|---|---|
| Where does each running bill wait, and on whose desk? | Project O2C screen, with the discovered process map of how bills really flowed | Yes, once an adapter feeds the bill events |
| Which client pays slow against its own terms? | Project Client screen | Yes |

| Who is told, by when, and did the number move? | Alerts and Tickets, auditor | Yes |
| Ask "which job holds the most money?" | Ask Crestline, company scope | Yes |

Limits stated plainly (kept off the printed pages unless noted):
- No filing names an ERP, so the booklet says "ERP". The adapter is built first in the pilot.
- Joint venture roll-up (several JVs under one company view) is not claimed. No scope card is printed.
- Only the receivable leg is priced. Stock days, vendor credit and certification days are not published, and the company's creditor days are on a different basis, so they are never paired with debtor days.
- No interest: no borrowing rate is disclosed.
